# 反重力（Antigravity）出图适配

本环境遵守 [跨程序镜头交付流程](workflow-contract.md) 和 [共同出图约束](render-adapters.md)。先按当前工具实际能力核对是否可直出镜头原画幅、传入底图及必要参考，并保护局部编辑锁定项。满足时调用该环境原生图像工具，保存原始结果后统一验收。

旧版「垫 16:9 → 回切」不适用。本项目禁止预垫、加黑边、裁切或拉伸来适配固定画幅。若当前环境无匹配能力，改用满足条件的本地或经确认工具（如确需用 A2E，先查当前安装的帮助与模型能力，核对命令、参考图传入方式和原画幅；不要硬套 21:9）；否则交简报、底图和参考供接续，明确待出图。参考查找与 GIF/PureRef 交付不依赖生图工具，按同一项目规范执行。
