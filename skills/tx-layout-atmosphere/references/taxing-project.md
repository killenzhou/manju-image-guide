# 踏星资料定位与镜头样例

## 定位

从当前项目工作区出发读 `PROJECT_ASSETS.md`、`踏星项目资料目录索引.md` 的相关部分。下列位置以现有 `Y:/TX/AI` 为例；换机器时把 `Y:/TX` 映射到实际项目根目录，勿假定盘符固定。

- 剧情：`AI/episodes_text` 对应集的定稿文本，缺失时到 `剧本/定稿`。只读与镜头相邻的场次。
- Layout：优先 `EP###/Layout/Story/Pr/sc###/Ep###_sc###_###_ly.mov`。若无单镜，查 `Video_Final/Layout` 的整集版；需要叙事上下文可查 `Video_Final/StoryBook`。精确到真实源帧，不以镜头表的小缩略图替代可访问的原片。比如 3-2-5 对应 `EP003/Layout/Story/Pr/sc002/Ep003_sc002_005_ly.mov`。
- 资产：`Assets/Scence`（目录确为此拼法）、`Assets/Character`、`Assets/Pro`、`Assets/其他设计`，按镜头可见项定位具体资产与版本，先在其 `Shading/` 目录查 `*_Shade.jpg`、`*_Shade.png` 等预览，也检查 `Shading/PNG/`；以实图为准，单张贴图或工程文件不算 Shading 预览。仅在缺少适用 Shading 图时，查该资产的 `Design/` 或已登记的设计图。既有工作区参考副本可辅助，但应核对真实内容与适用版本。
- 特效：确需设计时，读项目 `AI/.vfx/project.json` 和 `AI/.vfx/style-references.json`；查具体战技设计或审批证据，不把其他镜头颜色直接套进来。
- 交付：`AI/output`，建议 `EP003_sc002_054_FireCrystal_Atmosphere_<引擎>_v01_4K.png` 这类可检索文件名。

## EP003 sc005｜042–050 双倍波动掌：用户确认的叙事与用光设定

- **从后果倒推招式威力。** 这次双倍波动掌能打坏山体，命中后要在岩面留下可辨的巨大手印，非普通近身打击。042 蓄力不提前亮出全形；044–045 离手与飞行必须读到山体级的大尺度掌形压力和前后双层，不以细小、均匀的圆环作为主体。046 是擦身不是命中；047 起才出现岩体破坏；049–050 的破口与余尘需要衔接可辨的掌印轮廓，圆洞占位不代表定稿。
- **释放段以特效为主光、压暗背景。** 掌心与强压力面是清晰的发光来源，照亮陆隐迎光侧、手臂和面对冲击的岩面，光随距离衰减；压低原本抢眼的天空开口，保留云岩暗部层次，不把时段改成夜景。擦身只带短促侧光和风压；过了峰值，岩体与余尘靠残光和环境光继续交代结果，不持续泛蓝。
- **044 允许优化山体构图。** 在保留仰拍、人物位置与动作、攻击轴和画幅前提下，可调整近峰轮廓、山脊疏密和远山层次，使其托住巨掌、不挡人物。此放宽仅针对本镜的山形，不自动解锁别的镜头。
- **检索按力度与阶段筛。** 先搜「山体级青蓝掌形冲击／双层空气压缩／特效主光照亮岩壁」；命中再搜「巨大掌印岩面破坏／碎石抛散／余尘」。项目波动掌设计定掌形与青蓝靛色；`efx_0460`（0.64 秒）仅借宽厚压力和有方向的照明，`efx_0670`（0.60 秒）仅供后续山体尺度与局部受光，不借细光束；`efx_0236` 的薄气环最多作辅层。近似参考按借用层登记，样张不自动升为批准参考。

## 《踏星》视觉风格与景深统一规范

- **阶段风格统一**：
  - **地球篇**：有质感的科幻末世 CG 电影（粗粝混凝土、做旧氧化金属、重磅织物与微尘空气层次；克制写实、拒绝网游塑料油光与动漫滤镜）。
  - **离开地球之后**：辉煌大气、具备《沙丘》（Dune）级体量感与《星球大战》（Star Wars）式硬核科幻悬疑质感。
- **按景别分级控制景深（严禁广角硬虚焦）**：
  - **全景 / 广角 / 俯瞰（WS / EWS）**：`24mm–28mm T5.6–T8.0` 深景深，前中远景清晰可辨，靠空气透视与明暗分层拉纵深。
  - **中景 / 双人 / 过肩（MS / OTS）**：`35mm–50mm T3.5–T4.0`，人物主体与动作轨迹清晰，背景适度柔和过渡。
  - **特写 / 微距（CU / ECU）**：`85mm–100mm T2.0`，焦点锁在眼神或手部物体，背景自然渐进虚化。
- **精准单格资产输入**：官方拼版/三视图资产严禁整张黑边框直传，须裁切出对应视角的干净单格再传入；背身/动作镜不传正面大头照，避免带偏人物朝向。**统一先查 `Y:\TX\AI\asset_vault\vault.py resolve`，命中 `FRESH` 直接复用，缺失或源图更新时用 `vault.py crop` 裁入公共库沉淀共享；批量出图统一走 `scripts/tx_batch_runner.py`。**
