# 踏星｜场次美学参考

独立美学参考不是[场次 CK](workflow-contract.md#场次-ck先定标准再出图)。CK 用实际 Layout 的代表机位建立生产标准，可用原生图像工具，无须先做独立美学探索；说明里的候选批数不适用于 CK。

**任务定义：** 让 Agent 把用户想看的方向、剧本意图和 Layout 的空间／动作证据变成可生成、可挑选、可移交的参考图。参考不等于正式镜头，不代替原片动态参考。明确要求参考就启动；常规出图已知方向就直接锁 Layout，不自动多开一轮。

## 1. 先把场次和要做的决定说清楚

- 以用户指定的集／场／镜、版本和本轮问题为起点，只读对应剧本段落、代表性 Layout／邻镜、必要的 StoryBook 和可见资产。镜头使用哪版、看过哪一帧要留痕；剧本用来确认时段、情绪转折和动作因果，Layout 用来确认空间关系、站位、遮挡和动作阶段，Shading 用来核对造型与材质。没有 Layout 时可做场次概念，但标「待 Layout 核对」；关键证据确实矛盾又会改变方向时，先问一个问题。
- **观察 Layout，不等于拿 Layout 垫图。** 默认把空间、动作、尺度和已锁项目提炼成文字，概念构图可按参考目的选。只有确实需要锁定某个已确认的外观、且已同意素材进入该服务时，才传入选定 Shading／风格参考；不把灰模当美学底图。若用户要锁机位、同镜精修或原画幅成片，走正式镜头流程。
- 先写一句「用户看完要选什么」，再选参考类别；一批只围绕一个主要决策。仅当用户要多个独立方向时才拆批，不把每个方向都生成一轮当作默认。

| 类别 | Agent 从证据中提取 | 一批优先比较／正式镜头只借什么 |
|---|---|---|
| **特效美学** | 先用已确认的技能设定和特效设计；明确需要设计时走项目特效分支。按剧情定蓄力、释放、命中或余波，理清发力点、主形和走向、遮挡、受光及环境反馈。 | 针对同一阶段比较一个变量，如主弧的曲率、贴地扩散或边缘碎裂；只借选中的轮廓、流向、分层或介质反应。形态应能转译为 UE 条带／拖尾／碎粒等结构，但静帧不声称验证动态或实现。 |
| **灯光／质感** | 从剧本定时段与感受，从 Layout 找表演焦点和可解释的光源，从 Shading 核表面材质。明确谁接光、哪块压暗、湿石／金属／布料如何分开、雾尘如何分层。 | 保留同一时段、地标和材质，比较主光方向、明暗比、反光粗糙度或空气层中的一项；只借场次的用光逻辑和材质读法，不套整张图的调色与布景。 |
| **创意参考图** | 先写创意要回答的问题，如威压从空间比例、剪影还是负空间来；注明哪些是证据、哪些是新提案、哪些属性允许探索。 | 选一个探索轴，保持叙事、角色身份、关键地标与项目视觉基准；只借获选的视觉点子。不把提案当作已批准设计，不强加特效描写。 |

## 2. Agent 如何写提示词

先保存一份 `brief.json`：`scene`、`goal`、`evidence[]`（实际来源／镜号／帧号或时间点及观察）、`locked[]`、`explore`、`batches[]`（类别、假设、最终 prompt、画幅／分辨率／张数、明确排除项）、`status`。证据不足的细节写为假设，不冒充剧本事实。

先按[《踏星》创意出图提示词规范](../../../踏星_创意出图提示词规范.md)选 A 场景氛围或 B 贴镜特效／光照；两条路线的选图问题、详细稿篇幅、按需求调整的描述比例、实例与验收以该规范为准。普通综合创意允许相关细节联动；仅对照组固定其他条件。把画质要求译为可见的光线、材质或介质反应，不把“8K／UE5”、资料路径、内部镜号或制作清单当提示词。

四张是**同一提示词的一批候选**，不承诺一张对应一个方向。若需要比较两个明确假设，定义 A/B 各自的提示词，保持剧本时段、叙事阶段和其他参数相同，只改指定变量；一次报清所需批数与积分。默认先跑一批。

## 3. 即梦 V8.2：只用于独立参考

- 明确要用 V8.2 时，用 [即梦官方画布 CLI](https://jimeng.jianying.com/ai-tool/install?from_page=banner)；本机可执行文件是 `%USERPROFILE%/.local/bin/dreamina-canvas.exe`，即便没有加入 PATH 也可用绝对路径调用。先核版本与实时模型：`model find "图片美学模型 V8.2" --type image`。已核对国区 1.3.0：`jm_image_model_yc_mj82`、t2i/i2i、1K/2K、固定 4 张；无锁底图的项目参考默认 21:9、2K、4 张，可按用户目标改画幅。路线 A 可文生图或引用 BG，路线 B 用本镜成图作底。旧 `dreamina` 不是此模型的入口。
- 先用下方命令做本地预检，不建画布、不上传、不生成。实际执行时指定已确认画布，保存节点后 `node quote`；用户明确同意该批费用后才确认并运行。用提交 ID 等待，下载单张原始文件并打开核对。提交结果不明时按原提交 ID 恢复，不重复扣费。精细度／风格化虽出现在模型规格里，本机 1.3.0 的 `node create image` 未暴露相应开关；若必须精确复刻「超高／400」，转普通网页界面，不假报参数。
- 同意生成不等于同意上传项目素材。未经同意不向新服务发送 Layout、Shading 或其他项目素材；传入的文字简报也遵守项目保密要求。V8.2 不可用时，先交已写好的提示词并标「美学参考待生成」；如用户接受其他模型，再按宿主规则生成并明确实际模型。不静默冒充 V8.2。

### 已验证的两条 V8.2 用法（EP003，20261118）

- **场景美术概念（无锁底图）**：i2i 传该场场景设计 BG 图（如 `TX_Assets_Design_JPG/Scence/<场景>/Design/`）作参考，按剧本场次写末世科幻氛围，出远景／空间设定候选。也可用纯 t2i。示例输出：`output/EP003_JimengV82_concepts_20261118/`。
- **创意镜头·特效重构（有成图底图）**：i2i 传**已完成成图**作底，先锁本镜剧情动作与原设计，再按本次重点展开特效形态／密度／流向、局部受光与材质反馈；机位、站位与场景结构仍以原镜为准。一个明确方向一个节点，同底图只改特效变量，各 4 张。示例输出：`output/EP003_JimengV82_restyle_20261118/`。
- **贴镜光照（与特效重构同属 B 路）**：用本镜已有成图，只改变本轮指定的受光关系，不顺带重做特效。缺成图先交草案，物理光源以镜头证据为准。
- **i2i 构图行为（实测）**：V8.2 把参考图当内容与风格提示，不锁几何。灰模 Layout 作底会被重构；已完成成图作底明显更贴合，但仍非像素级锁定。需锁构图／原画幅的正式镜头回原生 CK 流程；本线只交独立概念候选，选中的点子按参考登记回填。
- 提示词按实际镜头内容写：先核对镜头工作目录的记录、Layout 帧与剧本段落，确认该镜的技能／动作阶段（如炎火掌、暴风斩），不凭镜号或场名猜桥段。
- 21:9、2K 实际输出约 `3376×1440`；固定每节点 4 张，多方向＝多节点。已用画布：`踏星 EP003｜第三集单帧氛围图`（项目复用，不重复建画布）。

```powershell
$cli = Join-Path $env:USERPROFILE '.local/bin/dreamina-canvas.exe'
& $cli model find '图片美学模型 V8.2' --type image
& $cli node create image --dry-run --title '踏星·场次美学参考' --mode t2i --model jm_image_model_yc_mj82 --ratio '21:9' --resolution '2K' --count 4 --prompt $prompt
```

## 4. 交付与回填

- 存到 `work/<集场>_aesthetic_refs/<类别>/<批次>/`：`brief.json`、候选单图、实际模型／参数与运行记录；每张注记**建议借用／排除／理由**，可选总览，但不拿总览代替单图。光效盖住表演、时段漂移、关键地标被隐去、创意改掉叙事的图不进入推荐。默认状态「候选」，只有明确选择才登记。
- 交付时给候选路径、实际分辨率和建议优先选哪张；未生成时只称提示词。选中后回填正式 `brief.json` 的 `references[]`，例如 `role: aesthetic_lighting`、`aesthetic_vfx`、`aesthetic_creative`，每条都填 `file`、`borrow` 和 `exclude`；记录选择证据，不把候选当批准。Layout 决定机位、构图、有效画幅和动作；Shading 决定外观；参考只负责获选的视觉判断。正式渲染仍按[宿主适配](render-adapters.md)和[镜头验收](workflow-contract.md)。
