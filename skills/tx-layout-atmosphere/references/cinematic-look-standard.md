# 首版风格与参考库

## 出图

1. Layout 或用户指定底图锁原画幅、机位、动作、人物、道具与遮挡；场次 CK 和当镜美术管时段、光源逻辑和固有色。
2. 默认实际传入一张最匹配的已通过风格图。按景别与场景选择：室内人物可借柔光与自然退焦，动作或大空间可借前后景层次及暗部质感。夜戏有针对性样板时可借夜色、肤色或发丝／衣料的质感，不叠加整套参考。
3. 风格图只借成像观感；灯位、方向、强度、色温不照搬，按场次及审片反馈调整。提示词只写一两个本镜重点，按实际成图验收。独立试镜不代替场次 CK 或正式放行。

## 参考归档

- 原图、缩略图和索引统一保存在项目资产盘的风格参考目录，不把个人下载目录当正式路径。复制后校验文件完整性；原图不覆盖、不裁切。存储与备份策略由项目维护。
- 索引记录编号、原文件名、归档路径、尺寸、适用镜头、只借什么、不照搬什么及审批状态。选图库候选时按光色、人物材质、环境尺度或特效查阅，不把全库当样板，也不自动晋升为已批准。
- 风格样板测试可锁同镜 Layout、内容参考和画幅，只替换风格输入，按主体、层次、固有色和场次连续性逐镜比较。
- 参考库可用于筛选未来的风格 LoRA 数据，但不等于当前已经有训练集或模型。可在支持 LoRA 的图像模型中按风格筛图并留独立测试镜头，再用其候选成图作为图像参考；Codex 原生图像流程不依赖 LoRA 权重。
