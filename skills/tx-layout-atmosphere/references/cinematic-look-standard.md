# 《踏星》出图与审核简表

**先锁框架，不穿帮；风格细节看图再调。** 项目统一保真底线，不统一滤镜、场次光色或摄影参数。

## 出图前只定三件事

1. **锁画面：** Layout 或选定旧版是唯一构图依据。原画幅、机位、视场、动作、人物身份、数量、主要道具和遮挡不动。不裁、不补边、不拉伸。
2. **锁连续性：** 对照剧本、同场已通过的 CK、必要的美术和角色参考，保住时段、实有光源、固有色和剧情信息。确有冲突才先解决。灰模不定颜色，UI 不该把整场染蓝。
3. **给模型一个重点：** 一条叙事焦点，最多再补一条本镜的特殊要求。例如：「先读陆隐眼神，再读地图亮区；投影薄透，青光只照近处。」参考够用即可，不把验收清单、镜头参数或画质口号整段复制进提示词。

## 首版默认带已通过的样板

EP006 A/B 测试已选定 A 组作为后续首版默认：每镜选一张最贴合的已通过样板，优先把画面质感、主体清晰度与层次做出来。具体光源不照搬样板，在不破坏场次时段与连续性的前提下，可按审核反馈后期调整。见[样板登记](first-pass-look.json)：

- [陆隐住处](../assets/first-pass-look/ep006_sc003_063_soft-window.png)：对话、人物和室内，借柔光过渡、人物清晰度、背景自然退焦。
- [废弃超市](../assets/first-pass-look/ep006_sc004_095_action-depth.png)：群像、动作和大空间，借主次焦点、前中后层次、暗部仍有材质。

首版默认实传最贴合的一张风格图，不例行塞两张。输入顺序通常是：**本镜 Layout／选定底图 → 必要的当镜美术（如有）→ 已通过的风格图**。风格图只给成像观感，场次时段、光源、固有色、内容和机位仍以当镜证据为准；夜戏不因此变暖，暗室不因此加窗。用户指定本镜风格或同场另有通过样板时优先使用对应参考，并在简报中写清实际传入了什么。只有文字而没传参考图，不算已按样板执行。

夜戏可从[夜戏补充样板](first-pass-look.json)挑一张更贴合的图，用于光感、色调或人物质感，不与 A 组样板叠加；光源仍按当镜和同场连续性调整。

场景需要更具体的参考时，可查[逐图参考库](downloads-reference-library.md)，按光色、人物材质、环境尺度或特效挑一张最贴合的图；图库候选不替换 A 组默认，也不替代当场 CK。

提示词只需：「图一锁原机位、幅面和内容。最后一图只借〔柔光／景深〕。这镜先看〔焦点〕，保留〔本场光色或关键动作〕。」

## 首版之后再收细节

制作端先看有无穿帮：人物或道具变形、数量变动、空间/遮挡/尺寸失真、剧情信息看错、时段或固有色跑偏。发现先修；没穿帮就送审，不因个人风格偏好反复重抽。胶片颗粒、景深强弱、光晕、质感和神秘程度按成图与用户批注局部调整；已有认可样板的只继承适用部分，不跨场套色。已有场次 CK 门禁不变；小批试镜不替代通过。

## 审核

人工对照成图、Layout、分镜和适用美术；支持逐镜看图、对照、批注、通过或退回。返修出新版本，不覆盖旧档，不沿用旧版通过。

## 景别分级提示词密度（即梦 5.5 / 跳过 CK 路线适用）
- **特写 / 微距 / 单人半身近景（ECU / CU / MCU / 道具特写）**：元素少、构图紧，**不需要**把提示词硬凑到上限；精准锁定机位、表情微表演、服装伤态、关键材质与本场光色即可，避免冗余稀释焦点。
- **大场景 / 多人同框 / 复杂特效 / 多参考图镜头（WS / ELS / ≥2人 / 打斗特效 / ≥3张参考）**：需要充分写满并逼近上限（最大 5000 字，建议 4200–4900 字），写透空间纵深、多人站位防串味、服化伤态隔离、特效形态流向与环境道具细节，保障跳过 CK 后的跨镜一致性。
