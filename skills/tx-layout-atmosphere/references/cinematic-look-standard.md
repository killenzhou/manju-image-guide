# 《踏星》出图与审核简表

**先锁框架，不穿帮；风格细节看图再调。** 项目统一保真底线，不统一滤镜、场次光色或摄影参数。

## 出图前只定三件事

1. **锁画面：** Layout 或选定旧版是唯一构图依据。原画幅、机位、视场、动作、人物身份、数量、主要道具和遮挡不动。不裁、不补边、不拉伸。
2. **锁连续性：** 对照剧本、同场已通过的 CK、必要的美术和角色参考，保住时段、实有光源、固有色和剧情信息。确有冲突才先解决。灰模不定颜色，UI 不该把整场染蓝。
3. **给模型明确重点：** 按景别与是否有 VFX 决定提示词详略与光照写法——特写重前后镜光照衔接与局部清晰度且少词少参考；含 VFX 镜头写清人物与特效的光照关系；大场面重空间与防串味细节，不把验收清单或空泛画质口号整段复制进提示词。

## 首版用光原则（已取消固定风格样板）

首版默认**不传入**固定风格样板（不再默认套用固定 LUT 或预设参考图），依据剧本时段、分镜情绪、Layout 已有光源与设计固有色自主布光。

- **输入顺序**：**本镜 Layout／选定底图 → 必要的当镜干净资产（Shading 优先，官方拼版须先裁出干净单格）**；不带入与本镜无关的风格图。
- **同场样板迁移**：若同场已有用户明确确认的镜头成图，只迁移其亮暗组织、主体轮廓与材质质感判断，不跨场套色，不照搬参考构图。
- **物理前置清理**：场景参考图上不应出现的亮源（如竖条 LED 灯管、多余过曝侧窗）须先在参考图上物理抹除，防止出图受参考权重拉偏。

## 首版之后再收细节

制作端先看有无穿帮：人物或道具变形、数量变动、空间/遮挡/尺寸失真、剧情信息看错、时段或固有色跑偏。发现先修；没穿帮就送审，不因个人风格偏好反复重抽。胶片颗粒、景深强弱、光晕、质感和神秘程度按成图与用户批注局部调整；已有认可样板的只继承适用部分，不跨场套色。已有场次 CK 门禁（或明确跳过记录）不变；小批试镜不替代通过。

## 审核

人工对照成图、Layout、分镜和适用美术；支持逐镜看图、对照、批注、通过或退回。返修出新版本，不覆盖旧档，不沿用旧版通过。

## 景别分级提示词密度与 VFX 光照关系

1. **特写 / 微距 / 单人近景（ECU / CU / MCU / 道具特写）**：
   - 更多注意**前后镜头的光照连续性**，突出特写主体部分让观众明显看清，并增强局部细节（眼神、微表情、皮肤/金属/织物肌理）。
   - **不需要写很多提示词，也不要塞过多参考图**——只要人物对、表情对、光照对即可，过多提示词和多余参考反而会导致模型跑偏或失真。
2. **VFX 特效镜头的光照关系**：核心是**突出人物与 VFX 之间的光照关系**。
   - **大场面 / 全景特效（WS / ELS）**：以**环境光与特效光影响的结合**为主，重点表现特效光源对人物与周围场景环境（地面、建筑、烟尘）的综合受光影响。
   - **近景 / 特写表现特效（CU / MCU）**：**主动压暗背景**，压缩无关环境杂光，集中突出表现**人物与 VFX 之间的明暗反差和受光关系**。
3. **大场景 / 多人同框 / 复杂特效 / 多参考图（即梦 5.5 跳过 CK 适用）**：
   - 需要充分写满并逼近上限（最大 5000 字，建议 4200–4900 字），写透空间纵深、多人站位防串味、服化伤态隔离、特效形态流向与环境道具细节，保障跳过 CK 后的跨镜一致性。
   - 宽银幕 `i2i` 须显式传入 `--ratio 21:9`；写对白情绪时只转译神态微表演，不直接照抄带中文引号的台词原句（避免画面底部误烧录字幕）。
