# 踏星｜出图适配器与共同约束

适配器只负责把同一份镜头简报和图像输入变成原始成图。证据、返修锁定项、出图提示词和交付验收始终走 [镜头交付流程](workflow-contract.md)。复刻的是制作过程和验收标准，不承诺不同模型像素相同。

| 执行环境 | 生成／编辑入口 | 使用条件 |
|---|---|---|
| Codex | 当前会话原生 GPT 图像工具 | 新镜以有效 Layout 作构图控制，返修以指定版本作编辑底图；实际传入角色、场景或 VFX 原帧。保留工具保存的原始结果。 |
| 其他程序 | 该程序可用的参考图生成、图生图、局部编辑或本地生产渲染（如 UE/Houdini + 合成） | 优先选支持目标原画幅和所有必要图像输入的工具；局部返修要能约束非目标区域。支持的比例或参考上限以实际能力为准。项目素材仅交给获同意的服务或本地流程。 |
| 当前无适配器 | 交接简报、提示词、底图、参考图及目标尺寸，标「待出图」 | 可由另一具备能力的程序或人工按同一简报接续；交接包不冒充成图。 |

## 镜头简报最小结构

- **镜头与时刻**：镜头 ID、来源帧或时间点、此刻发生的事。
- **锁定项**：机位/焦段感、视场/画幅、人物位置/占比/动作、关键遮挡、场景轮廓。
- **按用途排列的参考**：文件及用途，逐张写明不能带入的东西。用户已确认的参考优先。
- **叙事情绪与用光**：分镜/原帧的具体氛围提示、剧本时段和本帧焦点；写清主光从哪里来、落到哪一侧，轮廓光勾哪些人物/部位，弱补光保留哪些脸部或手部信息，什么位置必须压暗。交代掠射下的材质反差、前中远层次及有依据的环境增减；不要只用“电影感”或“8K”替代布光。
- **效果（可空）**：来源 → 形态 → 介质/物体反应；说明与前后镜的区别。使用真实特效视频时，记下来源 ID／时间或帧号、适配阶段、参考图路径、只借哪一层与排除项；把选中的帧作为独立效果参考实际传入，不作为底图或机位参考。
- **确认样板（如有）**：注明仅参考亮暗组织、人物轮廓、材质读法或介质层次；明确列出不得带入的画面元素和光源。每镜提示词单列本镜真实光源方向和同场连续性。
- **交付与排除项**：一张完整画面、目标比例、明确不应出现的内容与输出位置。

按镜头需要组织这些要点，只传有作用的参考。按原图的有效比例和构图直接输入、生成和交付，明确要求满幅、无新增黑边；不自动改成 16:9，不预垫、不加遮幅、不裁切、不拉伸。若结果偏离目标画幅，先在同一工具纠正；仍偏离时选择满足条件的适配器或标「待出图」。Layout 视频已有的时间码和预览黑框只可按可验证的边界提取有效区，不动真实画面。

生成提示词必须含项目画质基准：Cinematic 8K Masterpiece、UE5 Niagara/Chaos 级物理特效观感与超写实体积光，并说明本镜具体的光源、材质、景深和介质互动；这些是观感基准，不冒充真实引擎工程或原生 8K。
