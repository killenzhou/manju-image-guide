# 踏星｜UE 特效线条感设计规整（元素与落地方式）

《踏星》所有特效设计必须合乎 **UE5（Niagara / Ribbon / Trail / Flipbook）** 工程制作逻辑，**核心审美要求是“清晰、流畅、富有美感的线条感展示”**，严禁产出无结构、糊成一团的纯光斑或浓烟。

## 1. 四大类特效的线条设计元素

| 特效类型 | 核心线条元素（UE Niagara 对应思路） | 禁忌与避坑 |
|---|---|---|
| **气流 / 气浪** | 主引导流线（Ribbon 宽弧带包裹动作轴线）、次级伴随细丝（螺旋切线与高速拉伸丝带）、空气压缩透明折射边 | 禁止大团白雾遮脸或无方向的乱飘烟雾 |
| **刀光 / 剑气** | 锐利高光主弧线（首尾尖锐、厚度渐变）、伴随切风细线（沿挥砍轨迹平行排布）、尾部消散碎粒 | 禁止钝厚色块或扁平发光条 |
| **爆炸 / 冲击** | 放射状高速速度线（Velocity Sparks 射线）、非均匀压缩气浪弧线（破口处断续带张力）、碎石/碎晶拖尾线 | 禁止均匀死板的同心圆环或一团糊火球 |
| **能力对峙 / 碰撞** | 双色独立流线体系（各自保持色相、曲率与运动方向）+ 交锋中心高密度对撞射线与空间撕裂锯齿线 | 禁止双色混染成脏灰泥色或分不清发力源 |

## 2. 美学出图独立模块与落地衔接

> **触发方式**：
> 1. 用户明确提出 **「需要美学出图」「先做美学参考」** 等口令时，直接进入**美学出图独立模块**；
> 2. 常规出图遇到需要重点做特效创意或光影氛围升级的镜头/场次时，**先向用户确认是否启用美学出图**，获批后再执行。

1. **独立美学出图（整场 / 重点镜头光影与特效参考）**
   - **定位**：结合原美术设定与 Shading 基准，专为**整场戏**或**一组重点镜头**产出高审美光影/特效参考图（**不直接当最终成片，也不强锁单镜灰模 Layout**）。
   - **默认配置**：即梦网页端 **「图片美学模型 V8.2」**（`21:9 · 2K · 4张 · 生成精细度:超高 · 风格化强度:400`，可由浏览器子代理操作生成并下载；年轮 `悠船 V8.2` 可用时作备选）。
   - **提示词规则**：纯视觉描述 + UE5 Niagara Ribbon 条带/速度线/气流弧线等线条感词，**不垫灰模**，避开人体解剖/骨骼/未成年等易触发风控词及括号规格说明。
   - **产物归档**：保存至 `work/<集场>_aesthetic_refs/`，供用户挑选确认。

2. **锁 Layout 落地阶段（即梦 `5.0Pro` / A2E `gpt-image-2.6-sunburst`）**
   - **输入组合**：`Layout 原帧（锁机位姿态）` + `角色/场景 Shading（锁材质造型）` + `已选 V8.2 美学参考图（仅借光影氛围、冷暖反差或 UE 线条造型）`。
   - **验收要点**：确认成片中的特效线条保留了 V8.2 的美感与 UE Ribbon/Trail 可制作性，且未遮挡人物核心表演与前后景遮挡关系。
