# 踏星｜剧情效果 → PureRef 动态参考板

用户按踏星镜号或剧情说「找参考」「找类似特效桥段」「整理 .pur」时默认使用；不需要先问文件格式。只在用户明确只要链接、静帧或指定其他格式时变更交付。参考审阅与最终出图是两件事。

**完成条件**：每条入选动态参考都有独立循环 GIF；同一 GIF 内嵌在可由 PureRef 2.x 重开的原生 `.pur`；附原片链接、ID、起止秒、阶段、借用层和排除项。工作区 `output/` 下按集场或镜号建新版本。浏览页、总览图、JSON 作为辅助；单独给网页、原视频链接、截图或等待用户收藏都不是完整交付。

1. 将用户描述与定稿、分镜、Layout 对齐，提炼「动作阶段／画面因果／对象尺度／受光与后果」。未给集数或镜号且查不到对应项目镜头时，先按剧情阶段做板，Layout 标待补；不要把相似的库内镜头当作踏星 Layout。
2. 用 [真实特效视频检索](vfx-video-reference.md) 分阶段查询。先用结果 `preview_gif` 在本机快速看动态，入选再核对原片与准确秒段。区分同项目同版本与近似候选，注明借什么、排除什么；不把命中后果提前塞进离手镜。明确确认前，仍是候选。
3. `.pur` 中按叙事顺序摆三栏：**镜号和借用层／Layout 原帧（可并排最新版成图）／可播放 GIF**。统一参考编号、起止秒和适用阶段写在板内，不标来源库；可编辑 Markdown 保留原片与独立 GIF 链接。每镜按实际贴合度择 2–4 条为宜；不凑数。无真实合适素材的镜头标待补，不用静帧或未核视频冒充动态；如果全批都没有动态参考，先报告待补，不发空板。
4. GIF 由核对过的原片转出：上限 480px 宽、不放大小源、12fps、每段最多 3.5 秒、无限循环、至少 2 帧。项目缓存默认在 `E:/VFX_Reference_Library/GIF/EFX_Library/`，只复用源路径、秒段一致的缓存，入选不同秒段时只转该条，不更改原库或重转全库。GIF 供无声动态沟通，出图和色彩评估回到原 MOV/MP4。
5. 交付前逐个复开独立 GIF，验证文件可读、多帧及循环；用隔离设置打开原生 PureRef，在导入素材已移开的情况下复开并验各行对位。只用本地原片或已获许可的原文件；公开来源仅有播放页时只登记链接，不转存。缺 PureRef 时可以先交已有 GIF 和说明，但要标明 `.pur` 待生成，不用改扩展名的文件冒充。

## 运行

- `scripts/search_vfx_refs.py`：原索引检索结果附本地 GIF 路径、源片路径和缓存秒段；可生成小型 HTML 结果，不把全库 GIF 一次性加载。
- `scripts/vfx_gif_cache.py --ids efx_0460 efx_0670`：增量生成或验证所选 ID；仅首次建库、用户明确要批转或计划刷新时省略 `--ids`。运行结果在本地缓存 `last-run.json`。
- 在项目根目录用一条命令生成完整交付：`python -X utf8 .agents/skills/tx-layout-atmosphere/scripts/build_vfx_pur.py MANIFEST.json --output output/NEW_VERSION/NEW_BOARD.pur`。依赖 Python 3.11+、Pillow、imageio-ffmpeg 和 Windows PureRef 2.x；程序会查标准安装位置，也可加 `--pureref PURE_REF_EXE` 或设置 `PUREREF_EXE`。它在隔离设置中运行，不清空、关闭或保存用户现有板。
- 输出同名 `.pur`、`_GIF/`（板内同批 GIF）、`_说明.md`、`_浏览.html`、`_总览.png` 和 `_验证.json`。浏览页和独立 GIF 保持同目录相对关系，移动整包后仍能看预览；链接回原片需要接入原素材位置。大于 15 行按叙事分为多个新版本板；候选扩选网页可有更多条目，不替代精选交付。

## 清单格式

UTF-8 JSON，一条 GIF 一行，按镜头和阶段排序。先实际看片再填 `start` 与 `seconds`（秒数，不是结束点）。有项目库索引时用 `id` 查询，默认索引可用 `--library-index` 覆盖；其他程序可写 `source` 直接用原视频，不依赖本机索引。文件路径可绝对或相对于清单。已核对的缓存可通过 `--cache` 复用；无秒段的旧清单只为兼容已有缓存，新交付应显式写入已选段。没有 Layout 用 `layouts: []`。

```json
{
  "title": "踏星 EP003 SC006｜动态特效参考",
  "summary": "按叙事阶段；只参考点名效果层。",
  "rows": [
    {
      "shot": "3-6-69",
      "beat": "俯拍落地爆炸",
      "note": "借橙焰翻卷与贴地扩散，不借参考角色、机位或满屏白曝。",
      "layouts": [{"label": "Layout f027", "image": "plate_069.png"}],
      "reference": {"id": "efx_0083", "source": "original.mov", "start": 0.02, "seconds": 1.55}
    }
  ]
}
```
