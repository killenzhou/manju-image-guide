# 搜索、排序、选片与存档

## 来源和可见证据

- VFX/灯光/环境：先查现有踏星参考；按需查 B 站、YouTube、创作者原始作品页，以及按条目核许可的素材站。UI 查真实产品案例、设计系统或 Figma Community；字体优先字体作者、字库或开源项目；文案查有出处的案例。搜索失败只降级该来源，不编造项目或网址。
- 视频仅在确认原片且看过对应片段后填写起止秒；否则注明「片段待核对」。图片区分实际看过画面和只读到标题/摘要。无数据写 `null`，实际 0 写 `0`。互动值只从原始平台可见数据读取，保留来源与读取日期。
- 默认所有外部结果仅收藏链接。确认有权取得、转码及团队存档后，使用官方直接下载链接或用户交来的原文件；平台缓存/离线按钮不视为原文件导出许可。B 站、YouTube 默认仅登记来源及秒段。是否允许作为出图输入独立记录，默认关闭。公开搜索词只描述画面，不发完整剧本或未公开镜头标识。

## 候选 JSON

```json
{"query":"查找需求","groups":["灯光"],"items":[{"title":"条目标题","url":"https://example.com/item","source":"来源名称","category":"灯光","kind":"video","match":89,"value":75,"reason":"吻合哪些要求；不借哪些内容","verified":"metadata","segment":null,"metrics":{"views":null,"likes":null,"comments":null,"saves":null,"as_of":null},"engagement_allowed":false,"preview":null,"archive":"link","license_url":null,"dedup_key":null,"tags":["体积光"]}]}
```

`kind` 为 `video/image/font/ui/text/link`。`verified` 为 `media/metadata`，分别代表实际核对媒体或仅网页/标题资料。视频的 `segment` 为 `[起秒,止秒]`，仅已看过对应视频内容才填写。`preview` 可填有权展示的 HTTPS 图片，或本地文件 URI；缺预览留空，卡片可打开原页。`url` 使用原始页面或项目内可访问的本地绝对文件 URI。`dedup_key` 仅用于已核对为同一素材的转载；不要凭相似标题合并不同作品。

给 `match`、`value` 0–100 的编辑评分；不把标题说得像已经看过画面。相关度主要看关键约束、媒介与用途；参考价值看是否有足够清晰、可定位的信息。`archive` 默认 `link`；只有核对来源和用途许可后才标 `eligible`，并记录 `license_url` 或依据。`engagement_allowed` 默认关闭，核对条款允许后才打开；YouTube 始终关闭。只在同平台同类型、同指标有效数据样本至少 5 条时使用分位热度；评论权重低于点赞和收藏，缺失为中性，不跨平台比较绝对数量。

综合分为 70% 相似度、20% 参考价值、10% 热度，无可用热度时中性处理。同一查询先汇总、核对、去重再生成浏览页；候选不足就按实数交付。默认卡片按综合分降序；同分以相似度、参考价值和稳定键排序。结果板中的编号属于该次查询，入库后返回永久参考 ID。

## 入库约束

- 页面可跨批次多选，并复制候选编号回聊天。未选中的结果不入库。只有媒体已确认且许可明确才保存原图、视频原画质片段、GIF 或关键帧；否则只登记来源和备注。
- 下载只走已核对许可的 HTTPS 原文件地址；遇到登录、平台播放器、无官方下载或未知许可，保存链接并等待用户提供原文件。不要批量镜像站点。静态图保留原图，单帧 GIF 按需生成。视频按秒段保存近原画质片段并从源文件提三张 PNG；GIF 是动态沟通预览，不作出图色彩依据。
- 永久 ID 从来源与选中秒段产生。记录保存在独立条目目录，重复操作不覆盖原文件。若同一条目先收藏链接后获得原文件，媒体会以新版本条目入库，保留收藏记录。`lookup --for-generation` 仅返回明确允许且文件仍可读取的图片路径。
