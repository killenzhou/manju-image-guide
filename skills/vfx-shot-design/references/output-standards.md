# 按需输出标准

## 静帧特效
先看底图和目标区域，使用用户要求的画幅与机位。默认一张镜头合成设计；仅在用户需要制作拆解时补主体分层图/说明。

| 维度 | 落到画面与可执行说明 |
|---|---|
| 发光 | 核心与边缘的明暗比、发光面积、色阶和曝光上限；局部 bloom，不大面积泛白；无发光材质按需求保持无发光。 |
| 纹理 | 流向、疏密、厚薄、粗中细尺度、噪声频率；接近镜头才增加可读细节，不拿随机丝线伪造复杂度。 |
| 分层 | 主剪影/内核/外扰动/辅粒子/余波按需分工；分别描述透明度与前后遮挡，不强制六层齐全。 |
| 流体/粒子 | 发射点、主方向、速度趋势、涡卷、黏度观感、粒径分布、聚散与衰减；次级粒子服务主动作。 |
| 动态阶段 | 静帧标注处于蓄力/释放/峰值/扩散/衰减的哪个阶段，交代来向和去向。 |
| 镜头交互 | 景深、运动模糊、接触受光、反射、投影、人物遮挡、地面扬尘/冲击响应；只添加该效果合理需要的交互。 |

## 视频动态关键帧
- 先确定时长、fps、比例和镜头是否运动；没给数值时标“暂定”，也可用 0–1 归一化时间，别把建议值写成源素材事实。
- 用事件驱动划分：蓄力→释放→峰值/接触→扩散→衰减/残留；不适用的阶段可省略或改为持续流动。按镜头节奏定时间，非机械均分。
- 输出表字段：帧/时间或归一化时刻、主形态、发射/流向、层级/粒径/密度、亮度/颜色、与人物/场景交互、与前后帧连续项。
- 相邻帧锁定相机/焦段（除用户已要求的运动）、人物身份、场景地标、效果锚点、主流向、色彩和核心拓扑；峰值可变形但不得随机换一种招式。
- 将首帧/关键峰值/尾帧分别写成可生成提示词，提供跨帧共享约束与阶段增量；若工具只支持首尾帧，按真实能力交付，不声称多关键帧已上传。
- 静帧关键帧只检查设计连续性；真实速度、闪烁、穿帮及体积稳定性要查看实际视频后验证。暂未生成视频时明确标记。

## Style Match
记录参考文件/镜头号/时间码、批准来源、版本、观察尺度；抽取色相/饱和度/亮度比、主轮廓、纹理尺度、粒子密度、烟气厚度、衰减节奏、场景受光。按当前镜头景别换算尺度，不照搬参考相机。冲突时优先用户指定版本；新版本无批准记录则保留待确认。

## 制作说明最小形式
主结构→Niagara mesh/ribbon 或几何；表面→材质流动/扰动；烟/流体→Houdini 缓存或体积/flipbook；次粒子→Niagara；局部受光与合成→灯光/后期。只列与当前设计相关项，区分可复用现有资产、需新增资产、尚未核对项。没有实际引擎运行时写“设计可行性建议，未做性能实测”。
