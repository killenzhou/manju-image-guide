# 镜头特效设计

服务于视觉设计与图像/视频生成，不把设计图当作引擎资产。可跨项目复用；项目背景从当前项目配置读取，不把《踏星》审美强加给其他项目。

## 先判断适用范围
- 仅在用户明确要求特效设计/改效/特效统一/特效落地，或镜头上下文清楚涉及这些目标时自动启用。普通人物、海报、场景、调光、创意图及泛泛“更漂亮”按普通创作处理，不强塞模式、层表和制作拆解。
- 用户说“不用这套”“自由出图”“暂停特效规则”时，本次关闭；只有用户明确要求后续持续关闭时才延续。明确点名本 Skill 时可启用，但仍按用户所需交付。
- 图片修改保留原机位、透视、画幅、人物身份/姿态/服装、场景结构与非目标区域；仅在用户明确要求的范围内解锁。Concept 也不自动获得改机位、换人、重建场景的许可。

## 读取当前证据
1. 优先用户本轮明确要求、当前镜头/上传图、用户指定参考；再查当前工作目录及所属项目的 `.vfx/project.json`、`.vfx/style-references.json`。可由项目 AGENTS.md 指明配置路径；缺配置时使用通用规则，不臆造项目身份。
2. 从项目索引按镜头号/技能/角色检索相关素材，读实际原图或视频片段后再提炼风格。参考板可帮助检索，出图尽量选清晰单格或原始帧，不把版式、字幕、水印带入新图。
3. 区分“候选设计”“当前镜头”“已批准参考”；只有用户确认或真实审批记录才算批准。Final 文件夹、名称含 Pro、文件较新都不构成批准证据。静帧不证明动态，缩略图不证明全部原图细节。
4. 参考互相冲突时分别标注：谁控制机位/布局、谁控制特效形态、谁控制色彩材质。关键冲突短问一个问题；其余低风险缺失标注暂定，不拖延整个任务。

## 模式选择：理解整句话，不做单词触发器
先识别模式、用途、硬约束、美感诉求、匹配目标、交付类型。明确模式是主模式；其他诉求作为附加约束，别偷偷改标签。

| 优先级 | 真实意图 | 工作方式 |
|---|---|---|
| 1 | 用户明确 Concept / Production / Hybrid / Style Match，或中文等价指令 | 使用指定主模式。复合约束照样保留；显式条件彼此矛盾时说明冲突并短问，不用预设吞掉用户要求。 |
| 2 | 未指定模式，明确要匹配已批准镜头/现有特效 | Style Match；先查批准来源与目标镜头，保持特效语言一致，落地要求作为约束。 |
| 3 | 给制作执行、严格遵循现有资产/预算、按 UE/Houdini 实施 | Production；美感在此边界内提升，不退化成粗糙低配。 |
| 4 | 更漂亮但制作可做、既要视觉提升又兼顾落地 | Hybrid；优先轮廓、节奏、材质与局部亮度，不靠无限堆粒子。 |
| 5 | 明确自由探索、导演提案先找感觉、允许暂不计制作成本 | Concept；可拓展设计，但保留用户锁定项与项目世界观。 |
| 6 | 特效任务但只说更漂亮/更炸/更高级，或意图未明确 | Hybrid；“漂亮”不等于放弃落地。 |

- “Production，更漂亮但保持 UE 资产预算”仍是 Production；“Concept，但给一版可做拆解”仍是 Concept，附可做版本与差异，不擅改成 Hybrid。
- “Style Match + UE 可做”使用 Style Match，加 production_constraints。显式 Production 同时要求匹配时主模式 Production，附 style_match 约束。匹配只约束视觉语言，不复制参考镜头机位/人物。
- 请求匹配但尚无批准参考：标记“Style Match 待参考确认”；可按用户提供候选做暂定预览，明确其状态，别声称已匹配批准风格。缺少目标图时只交设计方向，标注尚未执行视觉匹配。
- 默认用一句简短说明“本次 Hybrid：提升美感，同时保留 UE 可做约束”。用户只要图时不展开流程说明。

## 设计与交付
按需读取 [输出标准](references/output-standards.md)。静帧优先一张所需镜头效果图，视频任务优先同一镜头的动态关键帧/时序设计，不强制每次三方案或多张图。
- 结构先于发光：核心/主体轮廓、主流动、外扰动、次级颗粒、尾迹/余波按需求取舍。每层说明形态、尺度、亮度关系与职责，不强制所有效果都有光环、符文或烟雾。
- 把发光、材质纹理、粒子/流体形态、运动阶段和镜头交互落实到可见设计；保持主体可读、透视遮挡与能量来源一致。
- **突出人物与 VFX 的光照关系**：大场面以环境光与特效光影响的结合为主，重点表现特效对人物与场景环境（地面、建筑、烟尘）的作用；近景表现特效时主动压暗背景，突出人物与 VFX 之间的明暗对比与受光关系。
- Production/Hybrid 给简洁实现映射：Niagara/网格或条带/材质流动/flipbook/Houdini 缓存或体积/合成；这是建议，不代表现有资产已具备。未提供预算就注明待确认，不编造帧率、粒子数、显存或工期保证。
- 需要生成媒体时使用当下可用生成工具，交付真实文件；只有提示词时明确交付的是提示词。静帧、关键帧图、动态示意、最终视频、引擎工程分别命名，不相互冒充。
- 修改后查看结果，对照机位、人物、结构、发光、参考一致性逐项检查。局部编辑可能溢出影响；发现锁定项漂移则局部返修，不以承诺替代实图验证。保留原图和新版本。
- 只将用户明确批准的结果登记为批准参考；普通满意评价不自动升级整套项目风格。持续更新需保留参考版本、来源与批准证据。
