# 踏星 · 特效工作台

1. 在《踏星》的 Codex 对话中说「打开踏星特效工作台」，用新插件打开镜头图或从剪贴板粘贴。如果当前打开的是旧版浏览器页面，先用「保存镜头工程」留存，再在新版点「打开镜头工程」；已有笔迹一起恢复。
2. 简洁模式里点击角色技能即可生效，无需写「主特效说明」，也无需手动建组。可以先画保护区、流向，再选技能；初次绑定会保留笔迹。切换形态、镜头时刻或加入／替换，会更新对应提示词与笔刷。
3. 画好后点击「直接出图」。工作台把原图、引导、保护区和参考图提交给当前 Codex 对话，由对话完成生成。新版对话入口无需下载出图包。已提交不等于成图已经完成。
4. 导入完成的结果图后，可预览、对比原图，或从此版本继续分叉。「保存镜头工程」用于保留画布和版本。「保存为特效预设」用于跨镜头复用，下个镜头重新画位置。
5. 多人、分区、文字包装走「高级」。简洁模式切换到不同技能时，已有绘制的前一个效果会暂时隐藏；可按需重新显示。保护区是出图引导，成图仍需检查。

首批技能：陆隐·波动掌（基础／双倍叠加），白雪·寒冰天赋（设计板表现）。设计板和裁出的局部图是候选参考；未把镜头时刻预设当作已审批的技能进阶。

原版 VFX Director 仍可单独使用。独立 HTML 仍是离线版本；需要直接出图请用 Codex 对话内安装的「踏星特效工作台」。


## 0.4.0 · 手绘草稿

打开镜头后点顶部「手绘草稿」，也可以从首页点「用演示镜头试笔刷」。能量带、冲击环和冰晶枝都是实际画出来的透明特效；在右侧选一笔可改色、宽度、强度，冲击环还可旋转。遮挡笔只影响特效，底图不改动。切换透明、黑底和白底可以检查边缘。

「导出透明 PNG」输出和镜头同尺寸的 RGBA 特效图；「导出遮挡」单独输出带 Alpha 的白色遮挡蒙版。「保存镜头工程」保留可编辑笔迹；建议更换底图前先保存。已保存的工程可以在手绘页直接打开。

「引导与生成」仍是原有流程，手绘草稿不会自动作为生成参考。时间轴、GIF、项目风格切换和参考图制笔刷属于后续阶段。

## 0.5.0 · 造型库、曲线与透视

打开「手绘草稿」→「展开造型库」，可按通用 20 种或踏星人物 10 种浏览和搜索。点预设后直接画；已经画好的，先在右侧选中一层，再选新造型并点「替换所选层造型」。原曲线、整层变换和深度保留。环形笔刷读取中心和外边界；换成环时，以原路径首尾定中心和尺寸。

对能量带、刀光、晶枝等沿线笔刷，可点「编辑曲线」：拖小方块移动锚点；拖选中锚点旁的圆形手柄调曲率；在曲线上双击加点；点「删除锚点」减点。环形保留自己的尺寸、旋转和环面俯仰／偏转控制。

每一笔是可独立选择的特效层。右侧「整层变换」可移动、等比缩放和旋转；「透视深度 · Z」可设起点／终点距离、画面消失点和环面朝向。Z 负值更近，正值更远；「放在遮挡层之前」可让该层不受手绘遮挡遮盖。此深度为单帧 2.5D，不读取真实场景模型、摄影机或人物深度。

踏星造型是根据项目资料与候选设计板做的可编辑草稿，不是原特效工程，也不是已审定资产。可按原流程导出透明 PNG、保存工程和继续修改。

## 0.6.0 · 手绘直接出图

在 **Codex 对话内** 打开「踏星特效工作台」，导入镜头后点「手绘草稿」。画好后点右下角「直接出图」。工作台自动发送干净源图、手绘合成草稿、特效足迹、保护区和独立透明草稿，要求按原路径、透视和遮挡精修，并在当前对话展示成图。不用先导出工程、出图包或手动上传。

「导出透明 PNG」和「保存镜头工程」仍可用于合成或留档，但不再是出图步骤。独立浏览器页面可画图和导出素材；若要直接出图，请从 Codex 对话打开已安装的工作台，而不是打开本地 HTML。
